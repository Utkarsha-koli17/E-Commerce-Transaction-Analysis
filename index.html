📌 Project Overview

This project processes massive e-commerce transaction datasets in real time. It converts raw streaming data into structured analytics using distributed systems and presents insights through a Flask-based reporting dashboard.

🔄 Data Pipeline Flow

Raw CSV Data → Apache Kafka → Spark ETL Processing → Airflow Orchestration → PostgreSQL Database → Flask API → Analytics Dashboard

This pipeline ensures real-time ingestion, fault tolerance, scalability, and structured transformation of high-volume datasets.
