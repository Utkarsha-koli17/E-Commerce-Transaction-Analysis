🚀 E-Commerce Big Data Analytics Pipeline

📌 Project Overview

This project implements an end-to-end Big Data Analytics Pipeline for processing large-scale e-commerce transaction data using Apache Kafka, Spark, Airflow, PostgreSQL, Docker, and Flask. It processes over 2 million records and transforms raw data into meaningful business insights.

🔄 Project Pipeline

Data Ingestion → Kafka Streaming → Spark ETL Processing → Airflow Orchestration → PostgreSQL Storage → Flask API → Dashboard Visualization
