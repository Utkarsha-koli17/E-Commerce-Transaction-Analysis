E-Commerce Big Data Analytics Pipeline

Kafka • Spark • Airflow • PostgreSQL • Flask • Docker

End-to-end system that processes 2M+ e-commerce transactions and converts raw streaming data into business insights.

🧠 Project Flow

📥 Data Source
📡 Kafka Streaming
⚙ Spark ETL
🧭 Airflow DAG
🗄 PostgreSQL
🌐 Flask API
📊 Dashboard
Raw data is ingested → streamed via Kafka → processed using Spark → orchestrated by Airflow → stored in PostgreSQL → exposed via Flask API → visualized in dashboard.
