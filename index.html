E-Commerce Big Data Pipeline

A production-grade distributed data engineering system built using Kafka, Spark, Airflow, PostgreSQL, and Flask that processes millions of transactions into business insights.

📌 The Story

We started with raw e-commerce data containing millions of transactions. The goal was to transform this noisy data into meaningful insights using a scalable big data architecture.
Every transaction flows through a distributed pipeline ensuring reliability, speed, and accuracy.
